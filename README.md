## Реализованные типы и контейнеры

### Аннотации типов

Все классы (`Character`, `Voin`, `Mag`, `TypedCollection`) снабжены полными аннотациями типов: параметры конструктора, атрибуты, возвращаемые значения.

### Generic-коллекция `TypedCollection[T]`

Обобщённая версия коллекции из ЛР-2. Параметризуется типом элементов `T`. Содержит методы:
- `add(item: T) -> None`
- `remove(item: T) -> None`
- `get_all() -> list[T]`
- `find(predicate: Callable[[T], bool]) -> Optional[T]`
- `filter(predicate: Callable[[T], bool]) -> list[T]`
- `map(transform: Callable[[T], R]) -> list[R]`

### Протоколы (структурные интерфейсы)

- **`Displayable`** – требует метод `display() -> str`.
- **`Scorable`** – требует метод `score() -> float`.

Классы `Voin` и `Mag` имеют эти методы (без явного наследования). TypeVar с ограничением `D = TypeVar('D', bound=Displayable)` гарантирует, что в `TypedCollection[D]` можно положить только объекты, поддерживающие `display()`.

## Реализованные стратегии и функции

Все стратегии вынесены в отдельный файл `strategies.py`.

### Стратегии сортировки

- `by_name(obj)` – ключ сортировки: имя (алфавитный порядок)
- `by_level(obj)` – ключ сортировки: уровень (числовой)
- `by_aura(obj)` – ключ сортировки: аура (у воинов), у магов возвращает 0
- `by_mana(obj)` – ключ сортировки: мана (у магов), у воинов возвращает 0
- `make_sort_by_attr(attr_name)` – фабрика, возвращает функцию для сортировки по любому атрибуту

### Функции-фильтры

- `is_alive(obj)` – оставляет только живых персонажей
- `is_warrior(obj)` – оставляет только объекты класса `Voin`
- `is_mage(obj)` – оставляет только объекты класса `Mag`
- `make_min_level_filter(min_level)` – фабрика, возвращает фильтр «уровень >= min_level»
- `make_max_health_filter(max_health)` – фабрика, возвращает фильтр «здоровье <= max_health»

### Callable‑стратегии (классы с `__call__`)

- `SortByAttribute(attr_name)` – сортировка по произвольному атрибуту (хранит имя атрибута)
- `FilterByType(class_type)` – фильтрация по типу класса (например, `FilterByType(Voin)`)
- `AddExperienceStrategy(amount)` – добавляет персонажу заданное количество опыта
- `HealStrategy()` – полностью лечит персонажа

### Методы коллекции `CharacterTeam` (добавлены в `collection.py`)

- `sort_by(key_func, reverse=False)` – сортирует коллекцию на месте, возвращает `self`
- `filter_by(predicate)` – возвращает новую коллекцию с отфильтрованными элементами
- `apply(func)` – применяет функцию к каждому элементу, возвращает `self`
- `map_to(transform_func)` – возвращает список результатов преобразования

### Сценарий 9: Магические методы

![Магические методы](./src/images/lab01/9.png)

str (пользовательский вывод):
+ Создаётся персонаж
+ Выводится результат print(character)
+ На экране появляется читаемое описание персонажа
+ Это метод, который вызывается, когда объект нужно показать пользователю

repr (отладочный вывод):
+ Выводится результат repr(character)
+ Появляется строка типа Character('Арагорн', 5, 150.0, 250.0)
+ Это представление для отладки, показывающее, как создать такой же объект

eq (сравнение персонажей):
+ Сравниваем двух персонажей с одинаковыми именем и уровнем — True
+ Сравниваем с персонажем с другим именем — False
+ Сравниваем с объектом другого типа — False

Показать, что наши объекты можно выводить и сравнивать как встроенные типы Python.
